# Каламкас — сайт специалиста

Двуязычный сайт (русский и казахский) для представления услуг Каламкас в Алматы. Запись ведёт в WhatsApp на номер `+7 747 595 17 28`.

## Запуск

Откройте `index.html` в браузере. Сборка и установка пакетов не нужны.

## Перед использованием для реальных клиентов

- Подтвердите точные названия услуг, образование и квалификацию специалиста. Сейчас на сайте указаны только направления из задания.
- Добавьте конкретные процедуры и цены, если захотите их показывать.
- Уточните адрес приёма и при желании разместите его на сайте. Сейчас указано только «Алматы».
- Изображения сгенерированы для оформления и не изображают Каламкас или её кабинет.
- Проверьте, что номер WhatsApp активен для записи.

Тексты страницы находятся в `index.html`, переводы и тексты сообщений WhatsApp — в `script.js`, оформление — в `styles.css`.

Энергетические практики описаны как услуги для расслабления и духовного опыта. Сайт не обещает лечения заболеваний.
